เมื่อไม่กี่ปีก่อน ธุรกิจขนาดเล็กที่อยากได้เว็บไซต์จริง ๆ ที่มีหน้าจองคิว ระบบล็อกอินสำหรับลูกค้า หรือแกลเลอรีที่อัปเดตเอง มีทางเลือกอยู่สองทาง คือจ่ายเอเจนซี่ 5,000 ถึง 15,000 ดอลลาร์ หรือไม่ก็ต้องต่อสู้กับเครื่องมือสร้างเว็บแบบลากแล้ววางที่ไม่เคยทำได้ตามที่ต้องการเลย

สิ่งนั้นเปลี่ยนไปแล้ว ตอนนี้ผู้ช่วยเขียนโค้ดด้วย AI เป็นคนเขียนโค้ด และคลาวด์โฮสต์ให้ในราคาไม่กี่ดอลลาร์ นี่คือหน้าตาของค่าใช้จ่าย:

รายการสิ่งที่คุณจ่าย
Claude (นักพัฒนา AI ของคุณ)240 ดอลลาร์ต่อปี
Azure SQL Database แพ็กเกจ Basic5 ดอลลาร์ต่อเดือน
โฮสติ้ง Google Cloud10 ดอลลาร์ต่อเดือน
ชื่อโดเมนของคุณเองจาก Unstoppable Domains100 ดอลลาร์ครั้งเดียว เฉลี่ยตลอด 10 ปี
รวม430 ดอลลาร์ต่อปี

คู่มือนี้เขียนสำหรับเจ้าของสตูดิโอถ่ายภาพที่มี 1-2 คน ศูนย์รับเลี้ยงเด็กที่บ้าน โรงเรียนสอนสเกตขนาดเล็ก หรือครูสอนพิเศษและโค้ชอิสระ คุณไม่จำเป็นต้องเขียนโค้ดเป็น แต่ต้องพร้อมทำตามขั้นตอนและอธิบายสิ่งที่ต้องการด้วยคำง่าย ๆ

สิ่งที่คุณจะได้ในท้ายที่สุด

  • ที่อยู่เว็บของคุณเอง (เช่น yourname.com) แทนที่จะเป็นซับโดเมนฟรีของเครื่องมือสร้างเว็บ
  • เว็บไซต์ที่เป็นของคุณทั้งหมด ไม่มี "ค่าแพลตฟอร์ม" รายเดือนที่แพงขึ้นทุกปี
  • ฟีเจอร์ที่เทมเพลตไม่มีขาย: รายชื่อรอคิวสำหรับคลาสสเกต พอร์ทัลสำหรับผู้ปกครองของศูนย์รับเลี้ยงเด็ก หน้าจองคาบเรียนสำหรับการสอนพิเศษ
  • ทุกอย่างเก็บอยู่ในบัญชีของคุณเอง คุณจึงเลิกใช้ผู้ให้บริการรายใดก็ได้

ขั้นตอน

1. สมัคร GitHub

GitHub คือที่ที่คุณอธิบายเว็บไซต์และเก็บซอร์สโค้ด ใช้ฟรี และจะเป็นของคุณตลอดไป ลองนึกภาพว่าเป็นตู้เซฟที่เก็บประวัติครบถ้วนของทุกการเปลี่ยนแปลง คุณจึงย้อนกลับจากข้อผิดพลาดได้เสมอ สมัครแล้วสร้างรีโพซิทอรีว่างสามอัน และเลือกการมองเห็นเป็น Private (ส่วนตัว) ทุกอัน ใช้ชื่อธุรกิจของคุณแทน YourName:

  • web-YourName สำหรับเว็บไซต์
  • api-YourName สำหรับโค้ดฝั่งเซิร์ฟเวอร์
  • db-YourName สำหรับสคริปต์ฐานข้อมูล

2. ติดตั้ง Claude Desktop

ดาวน์โหลดแอป Claude สำหรับเดสก์ท็อปของคอมพิวเตอร์คุณ ติดตั้ง แล้วลงชื่อเข้าใช้ด้วยบัญชี Claude ของคุณ คุณต้องใช้แพ็กเกจแบบเสียเงิน ซึ่งก็คือ 240 ดอลลาร์ต่อปีในตารางค่าใช้จ่ายด้านบน เมื่อคุณมี Claude แล้ว ขั้นตอนต่อไปนี้เป็นเพียงภาพรวม: Claude จะแนะนำคุณทุกรายละเอียดว่าต้องทำอะไรและทำอย่างไร

3. จดทะเบียนโดเมนที่ Unstoppable Domains

ไปที่ unstoppabledomains.com แล้วค้นหาชื่อ ชื่อสั้นชนะชื่อที่ฉลาดเกินไป โดเมนอาจมีราคาต่ำถึง 5 ดอลลาร์ต่อปี และจ่ายล่วงหน้า 10 ปีในราคา 50 ดอลลาร์จะคุ้มกว่า ซื้อด้วยบัญชีของคุณเอง และจดข้อมูลล็อกอินไว้ในที่ปลอดภัย โดเมนคือส่วนเดียวของธุรกิจที่ต้องเป็นของคุณเสมอ

4. สมัคร Google Cloud (GCP)

Google Cloud คือที่ที่เว็บไซต์ของคุณจะรันจริง ๆ สมัครได้ฟรี และคุณจ่ายเฉพาะส่วนที่ใช้เมื่อมีบางอย่างเริ่มทำงาน จากนั้นสร้างโปรเจกต์และเพิ่มบัตรชำระเงิน ทำสิ่งนี้ทันที: ตั้งการแจ้งเตือนงบประมาณที่ 15 ดอลลาร์ต่อเดือน นี่คือตาข่ายนิรภัย คุณจะได้รับอีเมลก่อนจะเกิดเรื่องไม่คาดคิดเป็นเวลานาน

5. สมัคร Microsoft Azure

ฐานข้อมูลของคุณอยู่ที่ Microsoft ดังนั้นคุณต้องมีบัญชีที่นั่นด้วย สมัครที่ azure.microsoft.com/free และเพิ่มบัตรชำระเงิน จากนั้นเปิดพอร์ทัล Azure แล้วตั้งการแจ้งเตือนการใช้จ่าย: ค้นหา Cost Management + Billing เลือก Budgets และสร้างงบรายเดือน 10 ดอลลาร์พร้อมการแจ้งเตือนทางอีเมลที่ 80%

6. สร้างฐานข้อมูล โดยเลือกแพ็กเกจ Basic

ในพอร์ทัล Azure ค้นหา SQL databases คลิก Create แล้วกรอกแบบฟอร์ม:

  1. Subscription: ปล่อยตามค่าเริ่มต้น
  2. Resource group: คลิก Create new และตั้งชื่อตามธุรกิจของคุณ (เช่น mystudio-rg)
  3. Database name: ชื่อสั้น ๆ เช่น mystudio-db
  4. Server: คลิก Create new ตั้งชื่อที่ไม่ซ้ำใคร เพราะจะกลายเป็นส่วนหนึ่งของที่อยู่ฐานข้อมูลของคุณ เลือกตำแหน่งที่ตั้งใกล้ลูกค้าของคุณ และจดไว้ว่าเลือกที่ไหน สำหรับการยืนยันตัวตนให้เลือก SQL authentication แล้วตั้งชื่อผู้ดูแลระบบและรหัสผ่านสุ่มยาว ๆ (30 ตัวอักษรขึ้นไป) จากตัวจัดการรหัสผ่านของคุณ
  5. Want to use SQL elastic pool? เลือก No
  6. Workload environment: เลือก Development
  7. Compute + storage: คลิก Configure database ใต้ Service tier เลือก Basic ตรวจสอบว่าแสดง 5 DTUs และ 2 GB แล้วคลิก Apply ราคา (ประมาณ 5 ดอลลาร์ต่อเดือน) จะแสดงในแบบฟอร์มก่อนที่คุณจะยืนยัน
  8. Backup storage redundancy: เลือก Locally-redundant ซึ่งถูกที่สุด
  9. ในแท็บ Networking ตั้ง Connectivity method เป็น Public endpoint เปิด Allow Azure services and resources to access this server และเปิด Add current client IP address เพื่อให้คุณเชื่อมต่อจากคอมพิวเตอร์ของคุณเองได้
  10. คลิก Review + create ตรวจสอบราคาที่แสดง แล้วคลิก Create ใช้เวลาติดตั้งไม่กี่นาที

อย่าพิมพ์ SQL เอง เมื่อฐานข้อมูลพร้อมแล้ว ให้บอก Claude ว่าธุรกิจของคุณต้องติดตามอะไร แล้วให้ Claude สร้างตารางให้

7. เปิดใช้ Cloud Run

Cloud Run คือบริการของ Google Cloud ที่รันเว็บไซต์ของคุณ มันจะตื่นขึ้นเฉพาะเมื่อมีคนเข้าชม และนั่นคือเหตุผลที่ค่าโฮสติ้งอยู่ที่ราว 10 ดอลลาร์ ก่อนอื่นเปิดใช้บริการ Cloud Run และ Cloud Build จากนั้นสร้างคอนเทนเนอร์ที่เชื่อมกับโค้ดของคุณ:

  1. ในคอนโซล Cloud Run คลิก Create service (หรือ Create container)
  2. เลือก Connect Repo ซึ่งจะปรับใช้โค้ดของคุณจากรีโพซิทอรีโดยตรง
  3. เลือก GitHub ลงชื่อเข้าใช้ แล้วเลือกรีโพซิทอรี web-YourName ของคุณ
  4. ในส่วนการปรับขนาด ตั้ง Maximum instances เป็น 1 เพื่อไม่ให้ค่าโฮสติ้งของคุณบานปลาย
  5. คลิก Create

8. เชื่อมต่อ Claude กับ GitHub

เชื่อมต่อบัญชี GitHub ของคุณกับ Claude ใน Claude ไปที่ Customize > Connectors เลือก GitHub Integration แล้วคลิก Connect จากนั้นในแชต คลิก + ที่มุมล่างซ้ายของกล่องข้อความ เลือก Add from GitHub แล้วเลือกรีโพซิทอรีของคุณ

Google Cloud ไม่ต้องเชื่อมต่อกับ Claude เพราะในขั้นตอนที่ 7 คุณได้เชื่อมมันกับรีโพซิทอรี GitHub ของคุณแล้ว หลังจากนั้น ทุกครั้งที่คุณเปลี่ยนซอร์สโค้ดใน GitHub ฟังก์ชันใหม่จะปรากฏขึ้นจริงภายในหนึ่งถึงสองนาที คุณบอก Claude ว่าจะสร้างอะไร แล้ว Claude จะบันทึกลง GitHub และ Google จะปรับใช้ให้อัตโนมัติ คุณไม่ต้องทำอะไรเพิ่ม แค่บอก Claude ว่าต้องการหน้าจอและฟังก์ชันอะไร

9. อธิบายเว็บไซต์ของคุณด้วยคำง่าย ๆ

นี่คืองานจริง เขียนหนึ่งหน้าเกี่ยวกับธุรกิจของคุณ: ลูกค้าของคุณคือใคร พวกเขาต้องทำอะไรบนเว็บไซต์ และคุณอยากให้พวกเขาเห็นอะไร ตัวอย่างเช่น:

"ฉันมีสตูดิโอถ่ายภาพที่ทำงานกันสองคน ฉันอยากได้หน้าแรกที่โชว์ผลงานที่ดีที่สุด หน้าสำหรับแต่ละประเภทการถ่ายภาพพร้อมราคา ฟอร์มขอจองที่ส่งอีเมลมาหาฉัน และหน้าแกลเลอรีส่วนตัวที่ลูกค้าใส่รหัสเพื่อดูภาพของตัวเอง"

คำอธิบายที่ดีชนะทักษะทางเทคนิคได้ทุกครั้ง

10. สร้างทีละหน้า

อย่าขอทุกอย่างพร้อมกัน ขอหน้าแรกก่อน ดูมัน แล้วบอกว่าจะเปลี่ยนอะไร ("ขยายรูปให้ใหญ่ขึ้น" "สีอ่อนลง" "เอาเบอร์โทรไว้ด้านบน") จากนั้นค่อยไปหน้าถัดไป การแก้ไขแต่ละครั้งใช้เวลาไม่กี่นาที ไม่ใช่หลายสัปดาห์

11. ชี้โดเมนของคุณมาที่เว็บไซต์

ใน Cloud Run ให้เพิ่มโดเมนของคุณเอง แล้วคัดลอกเรกคอร์ดที่ได้ไปใส่ในการตั้งค่า Unstoppable Domains ของคุณ ภายในประมาณหนึ่งชั่วโมง ที่อยู่ของคุณเองจะแสดงเว็บไซต์ของคุณ พร้อมสัญลักษณ์แม่กุญแจ (HTTPS)

12. ปรับปรุงต่อไปเรื่อย ๆ

เพราะทุกอย่างเป็นของคุณ คุณจึงเพิ่มฟีเจอร์ได้ทุกครั้งที่นึกออก: หน้ารีวิวจากลูกค้า การสมัครรับจดหมายข่าว ตารางเรียนที่แสดงที่ว่าง อธิบายมัน ตรวจดู แล้วมันก็ขึ้นออนไลน์

คำเตือนตรง ๆ ไม่กี่ข้อ

  • รู้ขีดจำกัดของแพ็กเกจ Basic ราคาคงที่ ดังนั้นเดือนที่ยุ่งจะไม่ทำให้บิลสูงขึ้น แต่ 5 DTU เป็นเครื่องยนต์เล็ก และ 2 GB คือเพดานพื้นที่เก็บข้อมูล เพียงพอมากสำหรับการจองและฟอร์มติดต่อ แต่จะช้าหากทุกครั้งที่เปิดหน้าต้องไปเรียกฐานข้อมูล ให้ขอ Claude แคชหน้าสาธารณะ (เช่นรายการราคา) เพื่อไม่ให้ผู้เข้าชมเรียกฐานข้อมูลเลย และเก็บรูปภาพกับวิดีโอไว้ในที่เก็บข้อมูลบนคลาวด์ ไม่ใช่ในฐานข้อมูล
  • ล็อกฐานข้อมูลให้แน่น Cloud Run ไม่มีที่อยู่คงที่ เว็บไซต์ขนาดเล็กจึงมักอนุญาตการเชื่อมต่อจากทุกที่อยู่และพึ่งรหัสผ่านที่แข็งแรงกับการเชื่อมต่อที่เข้ารหัส วิธีนี้ใช้ได้ แต่ทำให้รหัสผ่านสุ่มยาว ๆ จำเป็นอย่างยิ่ง อย่านำไปใช้ที่อื่นเด็ดขาด
  • เก็บข้อมูลล็อกอินให้ปลอดภัย ใช้ตัวจัดการรหัสผ่าน อย่าวางรหัสผ่านหรือเลขบัตรลงในแชตเด็ดขาด และอย่าให้ใครใส่ไว้ในโค้ดของคุณ
  • ปกป้องข้อมูลของลูกค้า หากเว็บไซต์ของคุณเก็บชื่อเด็ก รูปภาพ หรือข้อมูลติดต่อ ให้เก็บเฉพาะสิ่งที่จำเป็นจริง ๆ ตรวจสอบว่ารัฐหรือประเทศของคุณกำหนดอะไร และเขียนหน้านโยบายความเป็นส่วนตัวด้วยภาษาที่เข้าใจง่าย
  • คุณคือเจ้าของ ดังนั้นต้องตรวจงาน Claude ทำงานเร็ว แต่คุณควรอ่านสิ่งที่มันสร้าง คลิกทุกปุ่ม และถามว่า "จะเกิดอะไรขึ้นถ้ามีคนพิมพ์อะไรแปลก ๆ ตรงนี้"

สรุป

ส่วนที่แพงของเว็บไซต์เคยเป็นเวลาของนักพัฒนา ต้นทุนนั้นพังทลายลงแล้ว สิ่งที่เหลือคือการรู้จักธุรกิจของคุณดีพอที่จะอธิบายมันได้ และนั่นคือสิ่งที่คุณทำได้ดีกว่าเอเจนซี่ใด ๆ อยู่แล้ว

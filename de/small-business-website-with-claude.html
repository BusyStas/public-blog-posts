Vor ein paar Jahren hatte ein kleines Unternehmen, das eine richtige Website wollte, mit Buchungsseite, Kundenlogin oder einer Galerie, die sich selbst aktualisiert, zwei Möglichkeiten. Es konnte einer Agentur 5.000 bis 15.000 Dollar zahlen oder sich mit einem Drag-and-drop-Baukasten herumschlagen, der nie ganz das tat, was man wollte.

Das hat sich geändert. Ein KI-Programmierassistent schreibt heute den Code, und die Cloud hostet ihn für kleines Geld. So sieht die Rechnung aus:

WasSie zahlen
Claude (Ihr KI-Entwickler)240 $ pro Jahr
Azure SQL Database, Tarif Basic5 $ pro Monat
Hosting bei Google Cloud10 $ pro Monat
Ihr eigener Domainname bei Unstoppable Domains100 $ einmalig, verteilt auf 10 Jahre
Gesamt430 $ pro Jahr

Dieser Leitfaden richtet sich an Inhaber eines Fotostudios mit 1 bis 2 Personen, einer Kinderbetreuung zu Hause, einer kleinen Eislaufschule oder an selbstständige Nachhilfelehrer und Coaches. Sie müssen nicht programmieren können. Sie müssen aber bereit sein, Schritte zu befolgen und in einfachen Worten zu beschreiben, was Sie wollen.

Was am Ende dabei herauskommt

  • Ihre eigene Adresse (zum Beispiel ihrname.com) statt einer kostenlosen Subdomain eines Baukastens
  • Eine Website, die Ihnen ganz gehört, ohne monatliche "Plattformgebühr", die jedes Jahr steigt
  • Funktionen, die kein Template bietet: eine Warteliste für Ihre Eislaufkurse, ein Elternportal für Ihre Kinderbetreuung, eine Buchungsseite für Ihren Nachhilfeunterricht
  • Alles liegt in Ihren eigenen Konten, sodass Sie jeden Anbieter jederzeit verlassen können

Die Schritte

1. Bei GitHub registrieren

Auf GitHub beschreiben Sie Ihre Website und bewahren den Quellcode auf. Es ist kostenlos, und es gehört Ihnen für immer. Stellen Sie es sich als Schließfach mit dem vollständigen Verlauf jeder Änderung vor, sodass Sie einen Fehler jederzeit rückgängig machen können. Registrieren Sie sich und erstellen Sie dann drei leere Repositories, jeweils mit der Sichtbarkeit Private. Verwenden Sie den Namen Ihres Unternehmens anstelle von YourName:

  • web-YourName für die Website
  • api-YourName für den Servercode
  • db-YourName für die Datenbankskripte

2. Claude Desktop installieren

Laden Sie die Claude-Desktop-App für Ihren Computer herunter, installieren Sie sie und melden Sie sich mit Ihrem Claude-Konto an. Sie brauchen einen kostenpflichtigen Tarif, das sind die 240 $ pro Jahr in der Kostentabelle oben. Sobald Sie Claude haben, sind die folgenden Schritte nur noch eine Übersicht: Claude führt Sie durch jedes Detail, was zu tun ist und wie.

3. Domain bei Unstoppable Domains registrieren

Gehen Sie auf unstoppabledomains.com und suchen Sie einen Namen. Kurz schlägt clever. Eine Domain kann schon ab 5 $ pro Jahr kosten, und es lohnt sich, 10 Jahre im Voraus für 50 $ zu zahlen. Kaufen Sie sie mit Ihrem eigenen Konto und notieren Sie die Zugangsdaten an einem sicheren Ort. Die Domain ist das eine Teil Ihres Geschäfts, das immer Ihnen gehören muss.

4. Bei Google Cloud (GCP) registrieren

Auf Google Cloud läuft Ihre Website tatsächlich. Registrieren Sie sich. Es ist kostenlos, und Sie zahlen nur für das, was Sie nutzen, sobald etwas zu laufen beginnt. Erstellen Sie dann ein Projekt und hinterlegen Sie eine Zahlungskarte. Tun Sie das gleich: Richten Sie eine Budgetwarnung bei 15 $ pro Monat ein. Das ist ein Sicherheitsnetz. Sie bekommen eine E-Mail, lange bevor etwas Überraschendes passiert.

5. Bei Microsoft Azure registrieren

Ihre Datenbank liegt bei Microsoft, also brauchen Sie dort ebenfalls ein Konto. Registrieren Sie sich unter azure.microsoft.com/free und hinterlegen Sie eine Zahlungskarte. Öffnen Sie dann das Azure-Portal und richten Sie eine Ausgabenwarnung ein: Suchen Sie nach Cost Management + Billing, wählen Sie Budgets und legen Sie ein Monatsbudget von 10 $ mit einer E-Mail-Warnung bei 80 % an.

6. Datenbank erstellen, mit dem Tarif Basic

Suchen Sie im Azure-Portal nach SQL databases, klicken Sie auf Create und füllen Sie das Formular aus:

  1. Subscription: Standardwert belassen.
  2. Resource group: Klicken Sie auf Create new und benennen Sie sie nach Ihrem Unternehmen (zum Beispiel mystudio-rg).
  3. Database name: etwas Kurzes, etwa mystudio-db.
  4. Server: Klicken Sie auf Create new. Geben Sie einen eindeutigen Namen ein, denn er wird Teil Ihrer Datenbankadresse. Wählen Sie einen Standort in der Nähe Ihrer Kunden und merken Sie sich, welchen. Wählen Sie als Authentifizierung SQL authentication und legen Sie einen Admin-Login und ein langes, zufälliges Passwort (mindestens 30 Zeichen) aus Ihrem Passwortmanager fest.
  5. Want to use SQL elastic pool? Wählen Sie No.
  6. Workload environment: Wählen Sie Development.
  7. Compute + storage: Klicken Sie auf Configure database. Wählen Sie unter Service tier den Tarif Basic. Prüfen Sie, dass 5 DTUs und 2 GB angezeigt werden, und klicken Sie auf Apply. Der Preis (etwa 5 $ pro Monat) steht im Formular, bevor Sie sich festlegen.
  8. Backup storage redundancy: Wählen Sie Locally-redundant, die günstigste Option.
  9. Stellen Sie auf der Registerkarte Networking die Connectivity method auf Public endpoint. Aktivieren Sie Allow Azure services and resources to access this server und Add current client IP address, damit Sie sich von Ihrem eigenen Computer verbinden können.
  10. Klicken Sie auf Review + create, prüfen Sie den angezeigten Preis und klicken Sie dann auf Create. Die Bereitstellung dauert ein paar Minuten.

Schreiben Sie das SQL nicht selbst. Sobald die Datenbank existiert, sagen Sie Claude, was Ihr Unternehmen erfasst, und lassen Sie die Tabellen anlegen.

7. Cloud Run einschalten

Cloud Run ist der Google-Cloud-Dienst, der Ihre Website ausführt. Er wacht nur auf, wenn jemand die Seite besucht, und deshalb bleibt die Hosting-Rechnung bei etwa 10 $. Aktivieren Sie zuerst die Dienste Cloud Run und Cloud Build. Erstellen Sie dann einen Container, der mit Ihrem Code verbunden ist:

  1. Klicken Sie in der Cloud-Run-Konsole auf Create service (oder Create container).
  2. Wählen Sie Connect Repo, das Ihren Code direkt aus einem Repository bereitstellt.
  3. Wählen Sie GitHub, melden Sie sich an und wählen Sie Ihr Repository web-YourName.
  4. Stellen Sie unter Skalierung Maximum instances auf 1. So wächst Ihre Hosting-Rechnung nicht.
  5. Klicken Sie auf Create.

8. Claude mit GitHub verbinden

Verbinden Sie Ihr GitHub-Konto mit Claude. Gehen Sie in Claude zu Customize > Connectors, wählen Sie GitHub Integration und klicken Sie auf Connect. Klicken Sie dann in einem Chat unten links im Nachrichtenfeld auf +, wählen Sie Add from GitHub und wählen Sie Ihre Repositories aus.

Google Cloud braucht keine Verbindung zu Claude, denn in Schritt 7 haben Sie es bereits mit Ihrem GitHub-Repository verknüpft. Danach erscheint jede Änderung Ihres Quellcodes in GitHub nach ein bis zwei Minuten live. Sie sagen Claude, was gebaut werden soll, und Claude speichert in GitHub, während Google es automatisch bereitstellt. Sie müssen nichts weiter tun, nur Claude sagen, welche Bildschirme und Funktionen Sie wollen.

9. Ihre Website in einfachen Worten beschreiben

Das ist die eigentliche Arbeit. Schreiben Sie eine Seite über Ihr Unternehmen: wer Ihre Kunden sind, was sie auf Ihrer Website tun müssen und was sie sehen sollen. Zum Beispiel:

"Ich führe ein Fotostudio mit zwei Personen. Ich möchte eine Startseite mit meinen besten Arbeiten, eine Seite für jede Art von Fotoshooting mit Preisen, ein Buchungsformular, das mir eine E-Mail schickt, und eine private Galerieseite, auf der Kunden einen Code eingeben, um ihre Fotos zu sehen."

Gute Beschreibungen schlagen technisches Können jedes Mal.

10. Eine Seite nach der anderen bauen

Bitten Sie nicht um alles auf einmal. Bitten Sie um die Startseite, sehen Sie sie an und sagen Sie, was zu ändern ist ("Fotos größer", "sanftere Farben", "meine Telefonnummer nach oben"). Gehen Sie dann zur nächsten Seite. Jede Änderung dauert Minuten, nicht Wochen.

11. Ihre Domain darauf zeigen lassen

Fügen Sie in Cloud Run Ihre eigene Domain hinzu und kopieren Sie die angezeigten Einträge in Ihre Einstellungen bei Unstoppable Domains. Nach etwa einer Stunde zeigt Ihre eigene Adresse Ihre Website, mit dem Schloss (HTTPS) inklusive.

12. Weiter verbessern

Weil Ihnen alles gehört, können Sie jederzeit eine Funktion hinzufügen, sobald Ihnen eine einfällt: eine Seite mit Kundenstimmen, eine Newsletter-Anmeldung, einen Kursplan, der freie Plätze zeigt. Beschreiben Sie sie, prüfen Sie sie, und sie ist live.

Ein paar ehrliche Warnungen

  • Kennen Sie die Grenzen des Basic-Tarifs. Der Preis ist fix, ein arbeitsreicher Monat erhöht Ihre Rechnung also nicht. Aber 5 DTUs sind ein kleiner Motor, und 2 GB sind die Speichergrenze. Das reicht für Buchungen und Kontaktformulare und ist langsam, wenn jeder Seitenaufruf die Datenbank abfragt. Bitten Sie Claude, öffentliche Seiten (etwa eine Preisliste) zwischenzuspeichern, damit Besucher die Datenbank gar nicht abfragen, und legen Sie Fotos und Videos im Cloud-Speicher ab, nicht in der Datenbank.
  • Sichern Sie die Datenbank ab. Cloud Run hat keine feste Adresse, deshalb erlauben kleine Websites oft Verbindungen von jeder Adresse und verlassen sich auf ein starkes Passwort und verschlüsselte Verbindungen. Das funktioniert, macht das lange, zufällige Passwort aber unverzichtbar. Verwenden Sie es nirgendwo sonst.
  • Halten Sie Ihre Zugangsdaten sicher. Nutzen Sie einen Passwortmanager. Fügen Sie niemals Passwörter oder Kartennummern in einen Chat ein, und lassen Sie sie niemals jemanden in Ihren Code schreiben.
  • Schützen Sie die Daten Ihrer Kunden. Wenn Ihre Website Namen von Kindern, Fotos oder Kontaktdaten sammelt, erfassen Sie nur, was Sie wirklich brauchen. Prüfen Sie, was Ihr Bundesstaat oder Land verlangt, und schreiben Sie eine verständliche Datenschutzseite.
  • Sie sind der Eigentümer, also prüfen Sie die Arbeit. Claude ist schnell, aber Sie sollten lesen, was es baut, jeden Button anklicken und fragen: "Was passiert, wenn hier jemand etwas Seltsames eingibt?"

Das Fazit

Der teure Teil einer Website war früher die Zeit des Entwicklers. Dieser Kostenfaktor ist eingebrochen. Übrig bleibt, Ihr eigenes Geschäft gut genug zu kennen, um es zu beschreiben, und das können Sie schon jetzt besser als jede Agentur.

Gesamt: etwa 430 $ pro Jahr, oder rund 36 $ pro Monat.

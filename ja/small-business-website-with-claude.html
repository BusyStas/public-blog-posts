数年前、予約ページや顧客ログイン、自動で更新されるギャラリーなど、本格的なウェブサイトがほしい小さな事業者には、選択肢が2つしかありませんでした。代理店に5,000～15,000ドルを払うか、思いどおりに動いてくれないドラッグ＆ドロップ式のビルダーと格闘するかです。

それが変わりました。今ではAIのコーディングアシスタントがコードを書き、クラウドがごくわずかな費用でそれを公開してくれます。請求額はこうなります：

項目費用
Claude（あなたのAI開発者）年240ドル
Azure SQL Database、Basicプラン月5ドル
Google Cloud のホスティング月10ドル
Unstoppable Domains で取る自分のドメイン名一度だけ100ドル（10年分）
合計年430ドル

このガイドは、1～2人の写真スタジオ、家庭保育、小さなスケート教室、個人の家庭教師やコーチの方に向けたものです。コードが書ける必要はありません。手順に従い、ほしいものをふつうの言葉で説明する意欲があれば十分です。

最終的に手に入るもの

  • ビルダーの無料サブドメインではなく、自分のアドレス（たとえば yourname.com）
  • 毎年値上がりする月額の「プラットフォーム料金」がない、完全に自分のものといえるサイト
  • テンプレートでは売っていない機能：スケート教室のキャンセル待ちリスト、家庭保育の保護者ポータル、家庭教師のレッスン予約ページ
  • すべて自分のアカウントに保存されるので、どのベンダーからもいつでも離れられます

手順

1. GitHubに登録する

GitHub は、サイトの内容を説明し、ソースコードを保管する場所です。無料で、永久にあなたのものです。すべての変更の履歴が残る貸金庫のようなものだと考えてください。間違えてもいつでも元に戻せます。登録したら、空のリポジトリを3つ作成し、それぞれ公開設定を Private（非公開）にします。YourName の部分には事業の名前を使ってください：

  • web-YourName：ウェブサイト用
  • api-YourName：サーバーのコード用
  • db-YourName：データベースのスクリプト用

2. Claude Desktopをインストールする

お使いのパソコン用の Claudeデスクトップアプリをダウンロードしてインストールし、Claudeのアカウントでサインインします。有料プランが必要です。これが上の費用表にある年240ドルです。Claudeを使えるようになれば、以下の手順は概要にすぎません。何をどうすればよいか、細かいところまでClaudeが案内してくれます。

3. Unstoppable Domainsでドメインを取得する

unstoppabledomains.com にアクセスして名前を検索します。気の利いた名前より短い名前のほうが勝ちます。ドメインは年5ドルほどからで、10年分を50ドルで前払いするほうがお得です。自分のアカウントで購入し、ログイン情報は安全な場所に控えておきましょう。ドメインは、事業のなかで常に自分のものでなければならない唯一の部分です。

4. Google Cloud（GCP）に登録する

Google Cloud は、あなたのサイトが実際に動く場所です。登録は無料で、料金は何かが動き始めたときに使った分だけかかります。次にプロジェクトを作成し、支払いカードを登録します。そしてすぐにこれをやってください：月15ドルで予算アラートを設定します。これは安全網です。想定外のことが起きるずっと前にメールが届きます。

5. Microsoft Azureに登録する

データベースはMicrosoftにあるので、そちらのアカウントも必要です。azure.microsoft.com/free で登録し、支払いカードを登録します。次に Azureポータルを開いて支出アラートを設定します。Cost Management + Billing を検索し、Budgets を選び、月10ドルの予算を作成して、80%の時点でメール通知が来るようにします。

6. Basicプランを選んでデータベースを作成する

Azureポータルで SQL databases を検索し、Create をクリックしてフォームに入力します：

  1. Subscription：デフォルトのままにします。
  2. Resource group：Create new をクリックし、事業の名前をつけます（例：mystudio-rg）。
  3. Database name：mystudio-db のような短い名前にします。
  4. Server：Create new をクリックします。データベースのアドレスの一部になるので、一意の名前をつけます。お客様に近いロケーションを選び、どれを選んだかメモしておきます。認証は SQL authentication を選び、パスワード管理ツールで管理者ログイン名と長いランダムなパスワード（30文字以上）を設定します。
  5. Want to use SQL elastic pool? No を選びます。
  6. Workload environment：Development を選びます。
  7. Compute + storage：Configure database をクリックします。Service tier で Basic を選びます。5 DTUs と 2 GB と表示されていることを確認して Apply をクリックします。確定する前に、フォームに料金（月約5ドル）が表示されます。
  8. Backup storage redundancy：いちばん安い Locally-redundant を選びます。
  9. Networking タブで、Connectivity method を Public endpoint にします。Allow Azure services and resources to access this server をオンにし、自分のパソコンから接続できるように Add current client IP address もオンにします。
  10. Review + create をクリックし、表示された料金を確認してから Create をクリックします。数分でデプロイされます。

SQLは自分で書かないでください。データベースができたら、事業で何を記録したいかをClaudeに伝え、テーブルを作ってもらいましょう。

7. Cloud Runを有効にする

Cloud Run は、あなたのウェブサイトを動かすGoogle Cloudのサービスです。誰かが訪れたときだけ起動するので、ホスティング料金が10ドル前後に収まります。まずCloud RunとCloud Buildのサービスを有効にします。次に、コードとつながったコンテナを作成します：

  1. Cloud Runコンソールで Create service（または Create container）をクリックします。
  2. リポジトリから直接コードをデプロイする Connect Repo を選びます。
  3. GitHub を選び、サインインして、web-YourName リポジトリを選択します。
  4. スケーリングで Maximum instances を 1 にします。これでホスティング料金が膨らむのを防げます。
  5. Create をクリックします。

8. ClaudeをGitHubに接続する

あなたのGitHubアカウントをClaudeに接続します。Claudeで Customize > Connectors を開き、GitHub Integration を選んで Connect をクリックします。次に、チャットでメッセージ欄の左下にある + をクリックし、Add from GitHub を選んで、リポジトリを選びます。

Google CloudをClaudeに接続する必要はありません。手順7ですでにGitHubリポジトリとつなげてあるからです。以降は、GitHubでソースコードを変更するたびに、新しい機能が1～2分で公開されます。何を作るかをClaudeに伝えれば、ClaudeがGitHubに保存し、Googleが自動でデプロイします。ほかにやることはありません。ほしい画面や機能をClaudeに伝えるだけです。

9. サイトをふつうの言葉で説明する

ここが本当の仕事です。事業についてA4一枚ほどにまとめます。顧客は誰か、サイトで何をしてほしいか、何を見てほしいか。たとえば：

「2人で写真スタジオをやっています。いちばんの作品を載せたホームページ、撮影の種類ごとに料金を載せたページ、私にメールが届く予約リクエストフォーム、そしてお客様がコードを入力して自分の写真を見られる非公開のギャラリーページがほしいです。」

よい説明は、技術力にいつも勝ります。

10. 1ページずつ作る

一度にすべてを頼まないでください。まずホームページを頼み、見て、直したいところを伝えます（「写真を大きく」「もっとやわらかい色に」「電話番号を上に」）。それから次のページへ進みます。1回の修正は数週間ではなく数分で終わります。

11. ドメインをサイトに向ける

Cloud Runで独自ドメインを追加し、表示されたレコードをUnstoppable Domainsの設定にコピーします。1時間ほどで、自分のアドレスにサイトが表示されます。鍵マーク（HTTPS）もついてきます。

12. 改善を続ける

すべてが自分のものなので、思いついたときにいつでも機能を足せます。お客様の声のページ、ニュースレター登録、空き状況を表示するクラスのスケジュールなど。説明して、確認すれば、公開されます。

正直な注意点

  • Basicプランの限界を知っておく。料金は定額なので、忙しい月でも請求は増えません。ただし5 DTUは小さなエンジンで、2 GBがストレージの上限です。予約や問い合わせフォームには十分ですが、ページを開くたびにデータベースを呼び出すと遅くなります。料金表のような公開ページはキャッシュするようClaudeに頼み、訪問者がデータベースを呼ばないようにしましょう。写真や動画はデータベースではなくクラウドストレージに置きます。
  • データベースを守る。Cloud Runには固定アドレスがないため、小さなサイトでは、どのアドレスからの接続も許可して、強いパスワードと暗号化接続に頼るのが一般的です。それでも動きますが、長いランダムなパスワードが不可欠になります。ほかの場所では絶対に使い回さないでください。
  • ログイン情報を安全に保つ。パスワード管理ツールを使いましょう。パスワードやカード番号をチャットに貼り付けたり、誰かにコードへ書き込ませたりしてはいけません。
  • お客様のデータを守る。サイトで子どもの名前、写真、連絡先を集めるなら、本当に必要なものだけにしましょう。お住まいの州や国の要件を確認し、わかりやすい言葉でプライバシーのページを書きます。
  • オーナーはあなたなので、仕事を確認する。Claudeは速いですが、作られたものを読み、すべてのボタンをクリックし、「ここで誰かが変なものを入力したらどうなる？」と考えるのはあなたの役目です。

まとめ

ウェブサイトで高かったのは、開発者の時間でした。そのコストは崩れ落ちました。残るのは、自分の事業を説明できるほどよく知っていることで、それはすでにどんな代理店よりもあなたのほうが得意です。

合計：年約430ドル、月にすると約36ドル。

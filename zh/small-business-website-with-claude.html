几年前，一家小企业想要一个真正的网站，有预约页面、客户登录或能自动更新的图库，只有两个选择：要么付给代理公司 5,000 到 15,000 美元，要么跟一个拖放式建站工具较劲，而它始终做不出你想要的效果。

这一切已经改变。如今由 AI 编程助手来写代码，云服务只需很少的钱就能托管。账单是这样的：

项目费用
Claude（你的 AI 开发者）每年 240 美元
Azure SQL Database，Basic 套餐每月 5 美元
Google Cloud 托管每月 10 美元
在 Unstoppable Domains 注册你自己的域名一次性 100 美元，分摊 10 年
合计每年 430 美元

本指南写给 1 到 2 人的摄影工作室、家庭托儿所、小型滑冰学校，以及独立的家教或教练。你不需要会写代码，但需要愿意按步骤操作，并用平实的话描述你想要什么。

你最终会得到什么

  • 你自己的网址（例如 yourname.com），而不是建站工具提供的免费子域名
  • 完全属于你的网站，没有每年上涨的月度“平台费”
  • 模板里买不到的功能：滑冰课的候补名单、托儿所的家长门户、家教的课程预约页面
  • 所有内容都存放在你自己的账户里，因此你可以随时离开任何供应商

步骤

1. 注册 GitHub

GitHub 是你描述网站、保存源代码的地方。它是免费的，而且永远属于你。把它想象成一个保险箱，保存着每次改动的完整历史，所以你随时可以撤销错误。注册之后，创建三个空仓库，并为每个仓库选择可见性 Private（私有）。用你的企业名称替换 YourName：

  • web-YourName：用于网站
  • api-YourName：用于服务器代码
  • db-YourName：用于数据库脚本

2. 安装 Claude Desktop

为你的电脑下载 Claude 桌面应用，安装后用你的 Claude 账户登录。你需要一个付费套餐，也就是上面费用表中每年 240 美元的那一项。有了 Claude 之后，下面的步骤只是一个概览：Claude 会详细指导你每一步该做什么、怎么做。

3. 在 Unstoppable Domains 注册域名

打开 unstoppabledomains.com，搜索一个名字。简短胜过巧妙。域名最低可以每年 5 美元，一次性预付 10 年只需 50 美元，更划算。用你自己的账户购买，并把登录信息记在安全的地方。域名是你的生意中唯一必须永远属于你的部分。

4. 注册 Google Cloud（GCP）

Google Cloud 是你的网站真正运行的地方。注册即可，它是免费的，只有在有东西开始运行后，你才为用到的部分付费。然后创建一个项目并绑定一张付款卡。马上做这件事：设置预算提醒，额度为每月 15 美元。这是一张安全网。在出现任何意外之前，你很早就会收到邮件。

5. 注册 Microsoft Azure

你的数据库放在微软那里，所以你在那边也需要一个账户。在 azure.microsoft.com/free 注册并绑定一张付款卡。然后打开 Azure 门户，设置支出提醒：搜索 Cost Management + Billing，选择 Budgets，创建一个每月 10 美元的预算，并在达到 80% 时发送邮件提醒。

6. 创建数据库，选择 Basic 套餐

在 Azure 门户中搜索 SQL databases，点击 Create，然后填写表单：

  1. Subscription：保持默认。
  2. Resource group：点击 Create new，以你的企业名称命名（例如 mystudio-rg）。
  3. Database name：取个简短的名字，比如 mystudio-db。
  4. Server：点击 Create new。起一个唯一的名字，它会成为你数据库地址的一部分。选择离你的客户较近的位置，并记下你选了哪个。身份验证选择 SQL authentication，然后用你的密码管理器设置管理员登录名和一个很长的随机密码（30 个字符以上）。
  5. Want to use SQL elastic pool? 选择 No。
  6. Workload environment：选择 Development。
  7. Compute + storage：点击 Configure database。在 Service tier 下选择 Basic。确认显示 5 DTUs 和 2 GB，然后点击 Apply。价格（约每月 5 美元）会在你确认之前显示在表单上。
  8. Backup storage redundancy：选择 Locally-redundant，这是最便宜的。
  9. 在 Networking 标签页，把 Connectivity method 设为 Public endpoint。打开 Allow Azure services and resources to access this server，并打开 Add current client IP address，这样你就能从自己的电脑连接。
  10. 点击 Review + create，核对显示的价格，然后点击 Create。几分钟内即可部署完成。

不要自己写 SQL。数据库建好之后，告诉 Claude 你的业务要记录什么，让它来创建数据表。

7. 启用 Cloud Run

Cloud Run 是运行你网站的 Google Cloud 服务。它只在有人访问时才会唤醒，这就是托管费用能保持在 10 美元左右的原因。首先，启用 Cloud Run 和 Cloud Build 服务。然后创建一个与你的代码相连的容器：

  1. 在 Cloud Run 控制台中，点击 Create service（或 Create container）。
  2. 选择 Connect Repo，它会直接从代码仓库部署你的代码。
  3. 选择 GitHub，登录，然后选中你的 web-YourName 仓库。
  4. 在扩缩设置中，把 Maximum instances 设为 1。这样可以防止托管费用不断增长。
  5. 点击 Create。

8. 把 Claude 连接到 GitHub

把你的 GitHub 账户连接到 Claude。在 Claude 中，进入 Customize > Connectors，选择 GitHub Integration，然后点击 Connect。接着在聊天中点击消息框左下角的 +，选择 Add from GitHub，再选中你的仓库。

Google Cloud 不需要与 Claude 建立连接，因为在第 7 步中你已经把它关联到了你的 GitHub 仓库。此后，每当你在 GitHub 中修改源代码，新功能会在一两分钟内上线。你告诉 Claude 要做什么，Claude 保存到 GitHub，Google 自动部署。你不需要做别的，只要告诉 Claude 你想要哪些页面和功能。

9. 用平实的话描述你的网站

这才是真正的工作。写一页关于你业务的说明：你的客户是谁，他们需要在网站上做什么，你希望他们看到什么。例如：

“我经营一家两个人的摄影工作室。我想要一个展示我最佳作品的首页，每种拍摄类型各有一个带价格的页面，一个会给我发邮件的预约申请表，以及一个私密图库页面，客户输入一个代码就能看到自己的照片。”

好的描述永远胜过技术能力。

10. 一次做一个页面

不要一次要求所有东西。先要首页，看一看，然后说明要改什么（“把照片放大”“颜色柔和一点”“把我的电话放在顶部”）。再进入下一个页面。每次修改只需几分钟，而不是几周。

11. 把你的域名指向网站

在 Cloud Run 中添加你的自定义域名，并把它给出的记录复制到 Unstoppable Domains 的设置里。大约一小时后，你自己的网址就会显示你的网站，并且自带小锁图标（HTTPS）。

12. 持续改进

因为一切都属于你，所以想到新功能随时都能加：客户评价页面、邮件订阅、显示剩余名额的课程表。描述它，检查它，它就上线了。

几点坦率的提醒

  • 了解 Basic 套餐的限制。价格是固定的，所以访问量大的月份不会让账单上涨。但 5 个 DTU 只是一台小引擎，2 GB 是存储上限。用于预约和联系表单绰绰有余，但如果每次打开页面都要查询数据库就会变慢。请让 Claude 对公开页面（比如价目表）做缓存，这样访客根本不会去查询数据库，并把照片和视频放在云存储里，而不是数据库里。
  • 锁好数据库。Cloud Run 没有固定地址，所以小型网站通常允许来自任何地址的连接，并依靠强密码和加密连接。这样可行，但也意味着那个很长的随机密码至关重要。永远不要在其他地方重复使用它。
  • 保管好你的登录信息。使用密码管理器。绝不要把密码或银行卡号粘贴到聊天中，也绝不要让任何人把它们写进你的代码。
  • 保护客户的数据。如果你的网站收集儿童姓名、照片或联系方式，只收集你真正需要的。了解你所在州或国家的要求，并写一个通俗易懂的隐私页面。
  • 你是所有者，所以要检查成果。Claude 很快，但你应该阅读它做出来的东西，点一遍每个按钮，并问一句“如果有人在这里输入奇怪的内容会怎样？”

结语

网站过去昂贵的部分是开发者的时间。这项成本已经暴跌。剩下的，是你要足够了解自己的业务，才能把它描述出来，而这一点你本来就比任何代理公司做得更好。

合计：每年约 430 美元，约合每月 36 美元。

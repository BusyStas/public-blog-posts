Несколько лет назад небольшой бизнес, которому нужен был настоящий сайт — со страницей записи, личным кабинетом клиента или галереей, которая обновляется сама, — имел два варианта. Заплатить агентству от 5 000 до 15 000 долларов или бороться с конструктором «перетащи и брось», который никогда не делал в точности то, что нужно.

Это изменилось. Теперь код пишет ИИ-помощник для программирования, а облако размещает сайт за копейки. Вот как выглядит счёт:

Это руководство для владельцев фотостудии на 1–2 человека, домашнего детского сада, небольшой школы фигурного катания, а также для частных репетиторов и тренеров. Вам не нужно уметь программировать. Нужно лишь быть готовым выполнять шаги и простыми словами описывать, что вы хотите.

Что у вас получится

  • Собственный адрес (например, yourname.com) вместо бесплатного поддомена конструктора
  • Сайт, который полностью принадлежит вам, без ежемесячной «платы за платформу», которая растёт каждый год
  • Возможности, которых нет в готовых шаблонах: список ожидания на занятия по фигурному катанию, кабинет для родителей в вашем детском саду, страница записи на уроки для репетитора
  • Всё хранится в ваших собственных аккаунтах, так что вы можете уйти от любого поставщика

Шаги

1. Зарегистрируйтесь на GitHub

GitHub — это место, где вы описываете свой сайт и храните исходный код. Он бесплатный и навсегда останется вашим. Представьте его как сейф с полной историей каждого изменения, чтобы всегда можно было отменить ошибку. Зарегистрируйтесь, затем создайте три пустых репозитория и для каждого выберите видимость Private (закрытый). Вместо YourName подставьте название вашего бизнеса:

  • web-YourName — для сайта
  • api-YourName — для серверного кода
  • db-YourName — для скриптов базы данных

2. Установите Claude Desktop

Скачайте приложение Claude для компьютера, установите его и войдите в свой аккаунт Claude. Вам понадобится платный тариф — это те 240 $ в год из таблицы расходов выше. Когда у вас есть Claude, шаги ниже — лишь обзор: Claude подробно проведёт вас через всё, что нужно делать и как.

3. Зарегистрируйте домен в Unstoppable Domains

Зайдите на unstoppabledomains.com и подберите имя. Короткое лучше хитрого. Домен может стоить от 5 $ в год, и выгоднее заплатить сразу за 10 лет — 50 $. Покупайте на собственный аккаунт и запишите данные для входа в надёжном месте. Домен — единственная часть вашего бизнеса, которая всегда должна принадлежать вам.

4. Зарегистрируйтесь в Google Cloud (GCP)

Google Cloud — это место, где ваш сайт будет по-настоящему работать. Зарегистрируйтесь. Это бесплатно, и вы платите только за то, что используете, когда что-то начнёт работать. Затем создайте проект и привяжите платёжную карту. Сделайте это сразу: настройте оповещение о бюджете на 15 $ в месяц. Это страховка. Письмо придёт задолго до того, как случится что-то неожиданное.

5. Зарегистрируйтесь в Microsoft Azure

Ваша база данных живёт у Microsoft, так что аккаунт нужен и там. Зарегистрируйтесь на azure.microsoft.com/free и привяжите платёжную карту. Затем откройте портал Azure и настройте оповещение о расходах: найдите Cost Management + Billing, выберите Budgets и создайте месячный бюджет в 10 $ с оповещением по почте на 80 %.

6. Создайте базу данных, выбрав тариф Basic

На портале Azure найдите SQL databases, нажмите Create и заполните форму:

  1. Subscription: оставьте значение по умолчанию.
  2. Resource group: нажмите Create new и назовите по имени вашего бизнеса (например, mystudio-rg).
  3. Database name: что-нибудь короткое, например mystudio-db.
  4. Server: нажмите Create new. Дайте уникальное имя — оно станет частью адреса вашей базы данных. Выберите расположение поближе к клиентам и запомните, какое выбрали. В качестве аутентификации выберите SQL authentication, затем задайте логин администратора и длинный случайный пароль (30+ символов) из вашего менеджера паролей.
  5. Want to use SQL elastic pool? Выберите No.
  6. Workload environment: выберите Development.
  7. Compute + storage: нажмите Configure database. В разделе Service tier выберите Basic. Убедитесь, что показаны 5 DTUs и 2 GB, и нажмите Apply. Цена (около 5 $ в месяц) видна в форме до подтверждения.
  8. Backup storage redundancy: выберите Locally-redundant — самый дешёвый вариант.
  9. На вкладке Networking установите Connectivity method в Public endpoint. Включите Allow Azure services and resources to access this server и включите Add current client IP address, чтобы можно было подключаться со своего компьютера.
  10. Нажмите Review + create, проверьте указанную цену, затем нажмите Create. Развёртывание занимает несколько минут.

Не пишите SQL сами. Когда база данных появится, скажите Claude, что учитывает ваш бизнес, и пусть он создаст таблицы.

7. Включите Cloud Run

Cloud Run — это сервис Google Cloud, который запускает ваш сайт. Он просыпается, только когда кто-то заходит, поэтому счёт за хостинг остаётся около 10 $. Сначала включите сервисы Cloud Run и Cloud Build. Затем создайте контейнер, связанный с вашим кодом:

  1. В консоли Cloud Run нажмите Create service (или Create container).
  2. Выберите Connect Repo — код будет разворачиваться прямо из репозитория.
  3. Выберите GitHub, войдите и выберите репозиторий web-YourName.
  4. В настройках масштабирования установите Maximum instances равным 1. Так счёт за хостинг не будет расти.
  5. Нажмите Create.

8. Подключите Claude к GitHub

Подключите свой аккаунт GitHub к Claude. В Claude откройте Customize > Connectors, выберите GitHub Integration и нажмите Connect. Затем в чате нажмите + в левом нижнем углу поля сообщения, выберите Add from GitHub и укажите свои репозитории.

Google Cloud не нужно подключать к Claude, потому что на шаге 7 вы уже связали его со своим репозиторием GitHub. После этого каждое изменение исходного кода в GitHub появляется на сайте через минуту-две. Вы говорите Claude, что построить, а Claude сохраняет в GitHub, и Google разворачивает всё автоматически. Вам больше ничего не нужно делать — только сказать Claude, какие экраны и функции вы хотите.

9. Опишите сайт простыми словами

Это и есть настоящая работа. Напишите одну страницу о вашем бизнесе: кто ваши клиенты, что им нужно делать на сайте и что вы хотите им показать. Например:

«У меня фотостудия из двух человек. Мне нужна главная страница с лучшими работами, страница для каждого типа съёмки с ценами, форма заявки на бронирование, которая присылает мне письмо, и закрытая страница галереи, где клиенты вводят код, чтобы увидеть свои фотографии».

Хорошее описание всегда важнее технических навыков.

10. Стройте по одной странице

Не просите всё сразу. Попросите главную страницу, посмотрите и скажите, что изменить («сделай фото крупнее», «цвета мягче», «поставь мой телефон вверху»). Затем переходите к следующей странице. Каждое изменение занимает минуты, а не недели.

11. Направьте на сайт свой домен

В Cloud Run добавьте свой домен и скопируйте выданные записи в настройки Unstoppable Domains. Примерно через час по вашему адресу откроется ваш сайт, с замочком (HTTPS) в комплекте.

12. Продолжайте улучшать

Поскольку всё принадлежит вам, вы можете добавлять новую функцию, как только она придёт в голову: страницу отзывов, подписку на рассылку, расписание занятий со свободными местами. Опишите её, проверьте — и она уже на сайте.

Несколько честных предупреждений

  • Знайте ограничения тарифа Basic. Цена фиксированная, так что напряжённый месяц не увеличит счёт. Но 5 DTUs — маленький двигатель, а 2 GB — потолок хранилища. Этого хватает для записей и форм обратной связи, но будет медленно, если каждый просмотр страницы обращается к базе данных. Попросите Claude кэшировать публичные страницы (например, прайс-лист), чтобы посетители вообще не обращались к базе, а фотографии и видео храните в облачном хранилище, а не в базе данных.
  • Защитите базу данных. У Cloud Run нет фиксированного адреса, поэтому небольшие сайты обычно разрешают подключения с любого адреса и полагаются на надёжный пароль и шифрование соединений. Это работает, но делает длинный случайный пароль обязательным. Никогда не используйте его где-либо ещё.
  • Берегите свои логины. Используйте менеджер паролей. Никогда не вставляйте пароли и номера карт в чат и никогда не позволяйте никому вписывать их в ваш код.
  • Защитите данные клиентов. Если сайт собирает имена детей, фотографии или контакты, собирайте только то, что действительно нужно. Узнайте, что требуют законы вашего штата или страны, и напишите понятную страницу о конфиденциальности.
  • Вы владелец, поэтому проверяйте работу. Claude быстр, но вам стоит читать, что он строит, нажимать каждую кнопку и спрашивать: «что будет, если здесь кто-то введёт что-нибудь странное?»
